# LEO-Satellite-Collision-Predictor
Autonomous AI hackathon 2026

Airbus Challenge #1: AI-driven satellite collision avoidance. The pipeline in `collision_risk_pipeline.ipynb` estimates log10(Pc) for each conjunction data message and assigns a Safe / Elevated / Critical tier.

## Data
`train_data.csv` and `test_data.csv` are not in the repo (too large for GitHub). Download them from the hackathon Google Drive (`Challenge #1\archive(1).zip`) and place both files next to the notebook before running it.
